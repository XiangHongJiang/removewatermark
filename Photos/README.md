# 🖼️ 图片去水印工具

一个纯浏览器端的图片去水印工具，所有处理在本地完成，图片不上传服务器，隐私安全。

## ✨ 功能特性

- **矩形框选** — 拖拽标记规则水印区域
- **画笔涂抹** — 涂抹标记不规则水印区域，可调画笔大小
- **双算法模式**
  - **快速模式** — 边界扩散填充，适合纯色/渐变/简单背景，实时处理
  - **高质量模式** — PatchMatch 纹理合成，适合草地/墙面/天空等纹理背景
- **前后对比** — 滑块拖动对比处理前后效果
- **撤销/重做** — 支持快捷键 Ctrl+Z / Ctrl+Y
- **多轮处理** — 处理后可继续标记新区域再次处理
- **纯前端** — 零依赖、零后端、零隐私泄露

## 🚀 使用方法

### 在线使用

部署到 GitHub Pages 后直接访问即可。

### 本地运行

```bash
# 方式1: Python
python3 -m http.server 8000

# 方式2: Node.js
npx serve

# 然后浏览器打开 http://localhost:8000
```

### 操作步骤

1. 拖拽或点击上传带水印的图片
2. 选择工具（矩形框选 / 画笔涂抹）
3. 在图片上标记水印区域（可叠加多个区域）
4. 选择算法模式（快速 / 高质量）
5. 点击「去除水印」
6. 查看前后对比，满意后下载

## 🛠️ 技术原理

### 快速模式 — 边界扩散填充

从水印区域边界向内逐层填充，每个未知像素用周围已知像素的**高斯加权平均**来估算颜色。距离越近的像素权重越大。适合纯色、渐变等简单背景。

### 高质量模式 — PatchMatch 纹理合成

[PatchMatch](https://en.wikipedia.org/wiki/PatchMatch) 算法的简化实现：

1. **随机初始化** — 为每个待修复像素随机分配一个源位置偏移
2. **迭代传播** — 检查邻居的偏移是否更优，传播好的偏移量
3. **随机搜索** — 以当前最佳偏移为中心，递减半径随机搜索更优解
4. **填充** — 用最佳匹配位置的纹理填充待修复区域

适合有纹理的背景（草地、墙面、布料等），效果比快速模式更自然。

## 📦 部署到 GitHub Pages

1. Fork 或创建仓库，将代码推送到 `main` 分支
2. 进入仓库 **Settings → Pages**
3. **Source** 选择 **GitHub Actions**
4. 推送代码后，Actions 会自动部署
5. 部署完成后，在 Pages 设置页可看到在线访问链接

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 |
| `Esc` | 关闭对比弹窗 |

## ⚠️ 注意事项

- 图片处理在浏览器主线程进行，大图片（>4000×4000）高质量模式可能需要数秒
- 高质量模式对复杂纹理背景效果更好，但耗时更长
- 建议标记水印区域时稍微扩大范围，确保边缘也被覆盖
- 所有处理在本地完成，图片不会上传到任何服务器
